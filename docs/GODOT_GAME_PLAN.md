# ChogSekai: Star Stream of Monadia, the Godot game plan

Status: **agreed 2026-10-21** (written 11:15 UTC, 51.7 h before the 23 Oct 15:00 UTC deadline). Team answers to §12: install Godot 4.7.2, **3D view**, non-holders are view-only Stargazers, jobs re-roll every season.
Replaces the three.js client only once the Godot web build passes the de-risk gate in §9. Lore and older design: [WORLD_BIBLE.md](../chog-hivemind/WORLD_BIBLE.md). Rules: [RULES.md](../RULES.md).

> **One sentence:** 1,969 Chog NFTs live isekai lives on their own (working, shopping, adventuring, gossiping) while you, a **Constellation**, can only nudge them with skills, quests and hints until one of them becomes the **Hero** who slays the **Demon King**. Then the season resets and the stars choose again.

---

## 1. Decisions locked by this plan

| Decision | Choice | Why |
|---|---|---|
| Engine | **Godot 4.x stable, GDScript only** | Godot 4 cannot export **C#** projects to the web, so C# is out |
| View | **3D low-poly diorama**, Compatibility renderer, tilted god's-eye camera | Chosen by the team. Web exports require Compatibility (WebGL2), so: flat-shaded vertex colors, no SSAO/SDFGI, one shadowed sun, MultiMesh for every repeated object |
| Web export | **Single-threaded** (thread support off) | No COOP/COEP headers needed, so it runs on any static host and inside itch.io |
| Who simulates | **The existing Next.js server stays the brain** (agents, economy, battles, season director). Godot is a thin client over REST JSON. | The sim already works; it keeps running when nobody has the game open; no Godot multiplayer needed |
| Hosting | Godot build served by the Next.js app at **`/play`** (same origin) | Same origin means wallet session cookies work with no CORS. Fallback: itch.io HTML5 plus a bearer token and CORS. |
| Map art | **Terrain mesh built in Godot from an exported heightmap + color map** (generated by our existing `height()`/`colorAt()`), plus **CC0 Kenney 3D kits** (Fantasy Town Kit, Castle Kit, Nature Kit; glTF) for buildings, walls, trees and props | Reuses the proven terrain generator; consistent CC0 art with clean licensing |
| Chog art | Existing **portrait atlas** (`public/atlas/chogs.webp`, 64 px tiles, slot = tokenId − 1) drawn as camera-facing tokens by one `MultiMeshInstance3D` with a custom spatial shader (port of the three.js billboard shader) | One draw call for all 1,969; the real NFT art appears in-game |
| Fallback | Keep the three.js `/world` until `/play` passes §9 | Never be left without a working demo |

## 2. The world: Kingdom of Monadia

Continent layout stays as today (Hive Capital in the center, four nations around it, frontiers on the edges), plus the **Demon Realm** in the far north.

### 2.1 Cities and their buildings
Every city has a **standard district set**, so every job has a real workplace:

| Building | Job(s) working there | What it produces in the sim |
|---|---|---|
| Royal Castle (capital) / City Hall (4 nation capitals) | Administration | Posts guild quests, taxes, issues city decrees (buffs) |
| Barracks + City Walls | Army | Town defense against night monster raids |
| Adventurers' Guild | Guild clerks + **all adventurers** | Forms parties, hands out quests, pays rewards |
| Blacksmith | Blacksmith | Repairs gear; tools that raise farmer and miner output |
| Weaponsmith | Weaponsmith | Weapons (+ATK) for adventurers |
| Armorsmith | Armorsmith | Armor (+DEF) |
| Alchemist's Lab | Alchemist | Potions (healing between fights, cures injuries) |
| General Store | Shop owner | Basic supplies; the city's price index |
| Grand Library | Librarian, Scholar | Skill books: adventurers learn skills faster |
| Magic Academy | Mage teacher | Trains INT/WIS roles (Healer, Buffer) |
| Temple | Priest | Revives injured adventurers; blessings ceremony |
| Tavern / Inn | Innkeeper, Bard | Social hub: rumors spread, parties meet, morale |
| Restaurant / Bakery | Cook, Baker | Food gives stamina (more actions per day) |
| Flower Shop | Florist | Mood +; flowers gifted between Chogs raise affinity |
| Toy Shop | Toymaker | Mood + for civilians; festival items |
| Tailor / Jeweler | Tailor, Jeweler | Cosmetic gear; luck trinkets (LUK) |
| Market Square | Merchants | Moves goods between cities (caravans) |
| Farms, Fishery, Mines, Lumberyard (towns/villages) | Farmer, Fisher, Miner, Carpenter | Raw food and ore feed restaurants and smiths |
| Stables, Post Office | Stablehand, Courier | Faster travel; delivers hints and quests ("letters from the stars") |

**Places:** 5 cities (Hive Capital + Zapstone Citadel, Rainhaven, Glasshold, Lullaby Hollow), about 30 towns and villages, 6 dungeons (one per nation, the Hollow, and the Demon King's Castle), plus landmarks (Valley of Burning Candles, Weeping Falls, Glass Sea, Moonpetal Fields, Chog Pond, Rug Docks, Ruins of Testnet). All of them are already named in `data/world.json` or WORLD_BIBLE §2.

**Demon Realm (new, north):** Ashen Wastes → Bridge of Liquidation → **Castle of the Demon King**. It is sealed until all four Demon Generals fall.

### 2.2 Map production
1. `scripts/gen-world2.ts`: cities and building plots, roads (MST plus extra links), the Demon Realm, and a nav graph (nodes = building doors and road junctions). Output: `data/world2.json`.
2. `scripts/export-terrain.ts`: samples the existing `height()`/`colorAt()` on a 321×231 grid into `game/data/terrain.json` (heights + linear vertex colors). Godot builds one flat-shaded `ArrayMesh` from it at startup, so terrain matches the server's placement exactly.
3. Buildings and props: Kenney 3D kits (glTF, CC0) placed by Godot from `world2.json`, one `MultiMeshInstance3D` per model.

## 3. Jobs: all 1,969 Chogs are employed

Each season, jobs are assigned **randomly but reproducibly**:
- Seed = `season_number`.
- Weighted sampling without replacement against fixed quotas.
- Traits add affinity (e.g. Kings Robe → Administration ×3, Wizard Hat → Librarian/Mage ×3, Golden Armor → Army/Tank ×3, Farmer Shirt → Farmer ×3, Fwog accessory → Flower Shop ×2). Traits matter, but every Chog can land any job.

| Track | Job | Quota |
|---|---|---|
| Civic (300) | Administration (stewards, clerks, tax collectors, heralds) | 80 |
| | Army (soldiers, archers, guards, captains) | 220 |
| Crafts (365) | Blacksmith 60 · Weaponsmith 50 · Armorsmith 50 · Alchemist 60 · Tailor 40 · Jeweler 25 · Carpenter 50 · Toymaker 30 | 365 |
| Services (520) | Shop owner 70 · Librarian 40 · Mage teacher 40 · Priest 60 · Innkeeper 70 · Cook 90 · Baker 40 · Florist 40 · Bard 40 · Courier 30 | 520 |
| Land (265) | Farmer 100 · Fisher 40 · Miner 60 · Merchant 40 · Stablehand 25 | 265 |
| **Adventurers (519)** | Main DPS 110 · Sub DPS 110 · Tank 90 · Healer 80 · Support 65 · Buffer 64 | 519 |
| | **Total** (300 + 365 + 520 + 265 + 519) | **1,969** |

Exact quotas are tunable in `data/jobs.json`; the generator asserts the total equals the supply.

**Every job matters mechanically.** Civilians make the stock (gear, potions, food, books, mood) that adventurers buy, and adventurers bring back gold and loot. If smiths are idle, the Demon King fight gets harder. That makes a holder of a Florist Chog care too: flowers raise party cohesion.

### 3.1 Adventurer roles
| Role | Main stats | In battle |
|---|---|---|
| Tank | VIT, STR | Draws aggro, high DEF, taunt |
| Main DPS | STR or INT | Highest single-target damage |
| Sub DPS | AGI | Multi-hit, crits, debuffs |
| Healer | WIS | Heals, revives within a battle |
| Support | INT, LUK | Shields, cleanses, crowd control |
| Buffer | WIS, LUK | Party-wide ATK/DEF/speed buffs |

- **Stats:** STR, VIT, AGI, INT, WIS, LUK. Base 25 points from traits, plus role bias. **Level 1–50 per season**, **Rank F→S**.
- **Parties of 5:** Tank + Healer + Main DPS + Sub DPS + (Support or Buffer). The Guild forms them each morning from free adventurers, preferring Chogs with mutual affinity (follows, same house, tavern friends).

## 4. The season: Demon King arc (7 real days)

| Day | Chapter | What happens |
|---|---|---|
| 1 | **The Summoning** | All Chogs are summoned, jobs assigned, Status Windows revealed, the Guild opens |
| 2 | **First Floors** | Dungeon floors 1–3 open in every nation; night monster raids begin |
| 3 | **The Generals Stir** | The four Demon Generals appear in their nations' dungeons (boss fights unlock) |
| 4 | **Rising Stars** | Chogs with the most Story become **Hero Candidates** (top 10 shown publicly) |
| 5 | **The Seal Cracks** | Each general that falls weakens the castle seal; caravans are attacked |
| 6 | **March on the Castle** | Seal broken: raid parties attack the Demon King (3 phases, shared HP bar) |
| 7 | **The Hero Emerges** | Final battle; the Chog that lands the final blow or holds the most Story becomes **The Hero of Season N**, entered in the **Hall of Heroes** |

**Bosses:**

| General | Domain | Mechanic |
|---|---|---|
| General of Liquidation | Emberforge | Burn: needs Healers |
| Drowned Archivist | Tidecry | Silence: needs Support cleanse |
| Mirror Wraith | Prism | Reflects DPS: needs Buffers |
| Nightmare Shepherd | Dreamveil | Fear: party cohesion matters |
| **Demon King of the Unminted Abyss** | Castle | Phase 1 summons minions (Tank check), phase 2 drains (Healer check), phase 3 enrages (DPS race) |

**Director pacing.** Boss HP is shared and persistent, and every party fight chips at it. The director scales boss power to the live population's power curve so that:
- the Demon King can't fall before day 6,
- if it's still standing on day 7, a **"Last Stand"** event doubles every Constellation's Probability.

The climax always lands inside judging week.

**Season reset (isekai reincarnation):**
- **Reset:** levels, gear, skills, blessings, jobs (re-rolled with the new season seed), and the Demon King (a new variant).
- **Kept:** the Hall of Heroes, titles, each Chog's memories (as a "previous life"), and Constellation histories.

Season 1 starts at submission (Oct 23) and its finale lands on **Oct 30**, the last judging day.

## 5. Players are Constellations

Inspired by *Omniscient Reader*: watchers in the stars sponsor incarnations below. These are original names, with no copied characters.

| Who | How | Can do |
|---|---|---|
| **Constellation** | Connect a wallet that holds ≥ 1 Chog Genesis (live `ownerOf` on Monad) | Sponsor your own Chogs (your "Incarnations") with everything below |
| **Stargazer** | No wallet | Watch, read the Star Stream, cheer posts, drop rumors. The NFT gate stays essential. |

**Probability** (the daily resource) = 10 + 2 per held Chog, capped at 30. It resets at 00:00 UTC.

| Power | Cost | Effect | Free will? |
|---|---|---|---|
| **Hint** | 1 | One line delivered to your Chog ("the alchemist in Rainhaven sells fire potions") | The Chog may act on it, misread it or ignore it |
| **Grant Skill** | 3–8 by rank | Pick from a role-appropriate pool (from the 10,080-skill catalog). At most 3 granted per Chog per season. | Always granted. Its use depends on the Chog. |
| **Issue Scenario (quest)** | 4 | A personal quest with a target and reward ("defeat 3 slimes at Weeping Falls") | It can accept or decline, depending on bond and fit |
| **Blessing** | 6, once per Chog per season | Season-long passive (+10% one stat, or a role perk) | Always |
| **Indirect Message** | 0 | A flavor reaction broadcast to the Star Stream: *[The Constellation "Judge of Gas Fees" is pleased.]* | n/a |

- **Constellation Modifier:** each player picks a generated title from three options, e.g. *"Prisoner of the Green Candle"* or *"Demon-like Judge of Gas Fees"*.
- **Probability Storm:** spamming the same Chog (more than 3 powers a day) makes the next one backfire. This is an anti-abuse rule that doubles as a story beat.

## 6. How agents live (server)

The daily routine is a Smallville-style schedule template per job:
- morning at the workplace,
- noon errands (buying, eating),
- afternoon work, or a quest for adventurers,
- evening at the tavern or a restaurant,
- night home, or night watch for the Army.

Each tick runs these phases in order:

1. **Schedule:** move Chogs along the nav graph to their next slot.
2. **Work:** workplaces add stock.
3. **Trade:** adventurers buy gear, potions and food with gold.
4. **Guild:** form parties, assign quests.
5. **Battle:** resolve fights with a deterministic turn-based auto-battle (≤ 20 rounds, seeded, replayable). Results feed XP, loot, injuries and boss HP.
6. **Raids:** at night, monsters attack a town; the Army and adventurers present defend it.
7. **Social:** encounters, gossip, flowers and gifts, plus reactions to god actions. Text comes from Claude when a key is set, otherwise from the offline brain.
8. **Director:** season pacing, events, hero candidates.
9. **Stream:** write Star Stream messages (system lines, battle results, Constellation reactions).

The LLM only writes *text* (posts, dialogue, reactions to hints). **All mechanics are deterministic code**, which keeps cost low and results fair.

## 7. Godot client

```
game/                         (Godot project; exported to chog-hivemind/public/play)
  project.godot               Compatibility renderer, 1280×720 stretch "canvas_items", expand
  autoload/Api.gd             HTTPRequest wrapper, JSON, retry; base URL = same origin
  autoload/GameState.gd       snapshot + delta merge; signals: chogs_updated, stream_added, season_changed
  autoload/Wallet.gd          JavaScriptBridge → window.ethereum (eth_requestAccounts, personal_sign) → /api/auth/verify
  scenes/Main.tscn            World + HUD
  scenes/World.tscn           Terrain (ArrayMesh), Water, Sun + WorldEnvironment, Buildings (MultiMesh per kit model), ChogSwarm, Labels (Label3D pool), CameraRig
  scenes/ChogSwarm.gd         one MultiMeshInstance3D, custom shader samples the portrait atlas (INSTANCE_CUSTOM = atlas slot + house color), billboarded in the vertex shader; tweened walking
  scenes/hud/TopBar.tscn      season day + chapter, Demon King HP, your Probability, wallet button
  scenes/hud/StarStream.tscn  scrolling system feed ([SYSTEM] / [Constellation …] lines)
  scenes/hud/StatusWindow.tscn  job, role, rank, level, stats, skills, blessings, sponsor, memories
  scenes/hud/BuildingPanel.tscn shop name, keeper(s), stock, who's inside
  scenes/hud/GodPanel.tscn    Hint / Grant Skill / Scenario / Blessing (only on your own Chogs)
  scenes/hud/BossPanel.tscn   generals and Demon King status, hero candidates
  assets/map, assets/kenney, assets/atlas (copy of chogs.webp), theme.tres
```

**Camera:** god's-eye rig (pivot `Node3D` + `Camera3D`): left-drag pans, right-drag orbits (pitch clamped 25°–70°), wheel and pinch zoom (distance 25–560), bounds clamped to the continent. "Find my Chog" tweens the rig to it. Picking is done in screen space (project token positions, nearest within 18 px), as in the current three.js client.

**Performance budget (web):**
- Under 150 draw calls, 60 fps on an integrated GPU.
- All 1,969 Chogs in one MultiMesh draw call; labels pooled (≤ 80 `Label3D`); buildings and props one MultiMesh per model.
- Polling: `/state` every 5 s with deltas only.

### 7.1 API contract (server v2, JSON)
| Method | Path | Returns |
|---|---|---|
| GET | `/api/v2/world` | Regions, places, building plots `{id, type, city, x, y, capacity}`, roads, nav graph. Static and cached. |
| GET | `/api/v2/state?since=<tick>` | `{tick, season, day, chogs:[[id, x, y, buildingId, activity, hp%]], removed:[]}`: changed rows only |
| GET | `/api/v2/chog/:id` | Status Window: job, role, rank, level, stats, skills, blessings, gold, sponsor, last memories |
| GET | `/api/v2/building/:id` | Keeper(s), stock, occupants |
| GET | `/api/v2/stream?since=<id>` | Star Stream lines |
| GET | `/api/v2/season` | Chapter, bosses (HP, phase), hero candidates, Hall of Heroes |
| GET | `/api/v2/me` | Constellation: wallet, modifier, probability, owned Chogs |
| POST | `/api/v2/god/{hint,skill,scenario,blessing,message}` | Auth required; validated against ownership, Probability and caps |

## 11. Risks
| Risk | Mitigation |
|---|---|
| Godot web build fails, is too big or is slow | §9 de-risk gate at H4. Single-threaded export with brotli/gzip (expect a ~30–40 MB wasm before compression). The three.js fallback stays. |
| Wallet signing from Godot | `JavaScriptBridge` calls the same `personal_sign` flow already proven in the web app. If it's blocked, sign in on the Next.js page (same origin, so the cookie is shared) and let Godot read `/api/v2/me`. |
| Too much scope | §10 cut list. A deployed v1 by H24 is mandatory. |
| Boss fight ends too early or never | The director's power scaling + "Last Stand" rule; simulate a full season offline (`npm run season:sim`) before launch |
| Asset licensing | Kenney packs only (CC0), credited in the README and the submission |
| Free tier limits | Delta state API, static world JSON, ticks every 10 min with 30–60 agents; the LLM only writes text |
