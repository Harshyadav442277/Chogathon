2. Map major features to the official rubric before building.
3. Freeze feature additions at 70% of the agreed build time; use the rest for testing, demo preparation and submission.
4. Check setup from a fresh clone and document behavior when the network is unavailable.
5. Finish the entry before the official deadline, 23 October 2026 at 8:30 pm IST. Choose an earlier internal target when scheduling the work.
