The app is in [chog-hivemind/](chog-hivemind/); it runs locally and is not deployed yet. Setup: [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md#local-setup). **Submission deadline: 23 October 2026, 15:00 UTC / 8:30 pm IST.** Registration closed on 11 October. Our team's registration status has not been verified. See the [official dashboard](https://chogathon.chog.xyz/dashboard) and [rules](RULES.md) before proceeding.

## Work with a co-author

Clone the repository:

```sh
git clone https://github.com/Harshyadav442277/Chogathon.git
cd Chogathon
```

1. Agree who owns each task in `docs/PHASES.md` before editing the same files.
2. Create a branch, make a small change, then open a pull request into `main`.
3. Explain what changed and how you checked it. Record agreed decisions in `docs/MEMORY.md`.
4. Pull the latest `main` before starting another task.

For quick document edits, use GitHub's pencil button and choose a new branch and pull request. A public repository allows anyone to read it. Direct pushes require collaborator access; without it, use a fork and pull request.

Keep passwords, wallet keys, private contact details and judge login credentials out of this public repository. Supply private judge details through the event form.
